# ATM System

A simple Python ATM system that allows users to check their balance, deposit money, and withdraw money.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Simple menu system
- Input validation

## Technologies Used

- Python

## How to Run

1. Download.
2. Make sure Python is installed.
3. Open the project in VS Code.
4. Run the following command:

```bash
python atm.py
